# イベント概要

Microsoft Foundry や GitHub Copilot を活用して本気でビジネスを変えたいすべてのビジネスマンやエンジニアのためのコミュニティーの祭典「**AI Dev Day in Fukuoka**」を開催します！

東京、大阪に続き、今回は福岡での開催が決定しました。

**さらに！今年も開催予定の大手町での大規模カンファレンスについての続報も発表予定です！**

## こんな方におすすめ

- Azure AI 系サービスや Microsoft Foundry の最新情報をキャッチアップしたい
- GitHub Copilot をはじめとする AI ツールの活用法を学びたい

- AI 駆動開発の最先端を学びたい
- 同じ関心を持つエンジニアとネットワーキングしたい
- 責任ある AI、データ利活用戦略について知りたい
